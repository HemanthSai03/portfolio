# Portfolio - Hemanth Sai V

This project is a personal portfolio showcasing my experience as a Frontend Developer. It features a responsive design, project gallery, and interactive UI components built with React and Material UI.

## Getting Started

To run this project locally:

### `npm start`

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

## Tech Stack

- React
- Material UI
- Framer Motion
- React Scroll
